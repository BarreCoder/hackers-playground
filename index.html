HOW TO PLAY // FIELD BRIEFING
  1. Choose a difficulty and security complexity.
  2. Use ↻ NEW before starting to cycle through themed worlds; each world changes colors and controls. Use the theme-specific START control once to begin a session (for example LAUNCH LINK, INITIATE EVA, or INSERT COIN). Missions continue automatically until you use that world’s STOP control.
  3. Letter blocks begin with 010; number blocks begin with 1010. Enter the decoded key before the trace timer reaches zero.
  4. Press DECRYPT or Enter. Wrong keys or expired timers cost CryptoBytes; STOP GAME never costs currency. In PRO, every correct character changes the remaining cipher.
