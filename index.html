HOW TO PLAY // FIELD BRIEFING

DESKTOP: Decode each binary group using the left/right matrix key, then type the matching characters into the decryption buffer.

MOBILE: Touch either matrix rail, slide your finger until the magnifier is over the character you want, then lift your finger to enter it. Use ⌫ to remove the last entry.

You can enter correct or incorrect characters, but the buffer only accepts one character per binary group.

No UNLOCK button: when the final required character is entered, the system automatically attempts the decrypt.

In PRO mode, a correct prefix can mutate the remaining cipher while you work.
